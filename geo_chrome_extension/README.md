# GEO 三模型 Chrome 插件

插件直接操作当前 Chrome 中已经登录的豆包、腾讯元宝和文心一言标签页，不读取、导出或持久化 Cookie。

插件会根据网址自动识别模型页面，并在页面右下角显示一个可收起、适配窄屏和低高度窗口的小型控制面板。面板会显示网页登录状态、服务器连接状态、当前进度和最近日志。客户在 `/geo/` 提交诊断后，插件自动领取任务；同一任务中的三个模型并行采集，各模型内部依次完成 8 轮，而且每轮都会先创建并验证一个全新的独立会话，当前客户任务结束后才领取下一项。

插件参考 Scrapling adaptive 的保存与重定位机制，只在 Chrome 扩展本地存储中保存三类必要 UI 元素（问题输入框、新对话按钮、回答正文）的结构特征。当模型官网改动 class、层级或外围布局、固定选择器失效时，插件会按标签、文字、属性、父元素、兄弟元素和 DOM 路径相似度重新定位。学习数据按模型隔离且固定为少量记录，不保存网页正文或 Cookie。

输入与发送会优先使用官网稳定标识，再按输入区位置和控件语义选择；写入后会校验输入框内容，发送后会校验输入清空、用户消息出现、页面进入生成状态或对话路由变化。未确认发送成功时会在数秒内明确报错，不再等待完整回答超时。

每轮回答的正文、推荐判断、推荐名次和信源整理均在本机插件中完成。服务器不保存 Cookie、浏览器会话或重复 JSONL 中间文件，只接收客户网页展示所必需的最终报告正文、分析字段和信源链接。

未连接时，模型页面右下角控制面板会显示“设置 Worker 密钥并连接”。点击后会打开插件配置页；该密钥只用于本机插件连接服务器，与客户最终获得的随机报告地址不是同一种密钥。

## 加载

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 分别打开并登录豆包、腾讯元宝和文心一言网页；首次安装后刷新三个标签页。
5. 点击扩展图标，填写 `config/remote_worker.env` 中的 `MONITOR_WORKER_TOKEN`，点击“连接并检测”。密钥和连接配置会保存在本机 Chrome 扩展存储中，重启 Chrome 后自动连接；不会同步到服务器或其他设备，可随时点击“清除”删除。
6. 保持三个模型标签页打开。客户从 `/geo/` 提交后无需再点击插件，右下角面板会自动显示采集进度与日志；诊断完成后客户会进入服务器生成的随机报告地址。

如需在无痕窗口使用，请在扩展详情页开启“允许在无痕模式下运行”，并在无痕窗口内重新登录三个模型。
